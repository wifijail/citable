# Citable — AI Search Visibility Auditor

> **Одной строкой:** Citable показывает, могут ли ChatGPT, Claude, Perplexity и Google AI Overviews
> прочитать и процитировать ваш сайт — и что конкретно чинить, чтобы начали.

---

## 1. Проблема

За 2024–2026 трафик из классического поиска перетёк в генеративные ответы. Пользователь
получает ответ прямо в ChatGPT / Perplexity / AI Overviews и не кликает по ссылкам.
Единственный оставшийся канал — **быть процитированным источником** внутри ответа.

Но большинство сайтов технически невидимы для AI-краулеров, и владельцы об этом не знают:

| Что ломается | Почему это критично |
|---|---|
| `robots.txt` блокирует `GPTBot` / `ClaudeBot` / `PerplexityBot` (часто — случайно, через `User-agent: *`) | Сайт физически не может попасть в ответ |
| Контент рендерится только в браузере (CSR/SPA) | AI-краулеры в основном **не исполняют JS** — видят пустой `<div id="root">` |
| Нет `llms.txt` | Нет машиночитаемой карты «что тут вообще есть» |
| Нет JSON-LD (`Organization`, `Article`, `FAQPage`, автор, дата) | Модель не понимает, кто автор и насколько свежо → не доверяет |
| Контент не «отвечающий»: нет заголовков-вопросов, списков, определений | Нечего вырезать в цитату |
| `X-Robots-Tag: noindex`, битые каноникалы, мусорный HTML | Тихая невидимость |

Существующие SEO-инструменты (Ahrefs/Semrush/Screaming Frog) заточены под классический
поисковый индекс и **не проверяют AI-специфичные сигналы**. Ниша ещё не занята монополистом.

## 2. Решение

Веб-сервис + API: вводим URL → обычно за несколько секунд (режим сайта — дольше) получаем **AI Visibility Score (0–100)**,
разбитый на 6 категорий, с 20+ конкретными проверками. Каждая проверка даёт:
статус, найденное доказательство (evidence) и **точную инструкцию по починке** (fix).

Ключевая техническая ценность — собственный парсер `robots.txt` с корректной семантикой
(группы, longest-match `Allow`/`Disallow`, wildcards, `$`), прогоняемый по базе
**16 реальных AI-агентов** (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User,
Claude-SearchBot, PerplexityBot, Perplexity-User, Google-Extended, Applebot-Extended,
Bingbot, CCBot, Meta-ExternalAgent, Amazonbot, Bytespider, DuckAssistBot) с указанием,
какой агент за что отвечает (обучение / ретривал в реальном времени / индексация).

## 3. Целевая аудитория (ICP)

| Сегмент | Боль | Готовность платить |
|---|---|---|
| **SEO / GEO-агентства (2–20 чел.)** — основной ICP | Нужен новый продаваемый аудит клиенту + white-label отчёт | Высокая: продают аудит за $500–2000 |
| **B2B SaaS маркетологи** | Контент-маркетинг перестал приносить лиды, надо доказать причину | Высокая |
| **Инди-хакеры / основатели контентных сайтов** | Трафик упал, непонятно почему | Средняя ($7 — импульсная покупка) |
| **Dev-команды** | Нужно в CI проверять, что деплой не сломал AI-видимость | Средняя, но низкий отток (API в пайплайне) |

## 4. УТП

1. **Единственная метрика, которая измеряет именно AI-цитируемость**, а не позиции в Google.
2. **Мгновенный результат без регистрации** — скан работает сразу на лендинге (PLG-воронка).
3. **Actionable, а не «у вас 47 ошибок»** — каждая проблема со строчкой кода, которую надо вставить.
4. **API-first** — тот же аудит одной строкой в CI/CD, чтобы регресс ловился на PR.
5. **Zero-infra** — работает на free tier Vercel, стоимость обслуживания клиента ≈ $0.

## 5. MVP (то, что реализовано в этом репозитории)

- [x] Движок аудита: 54 проверки в 6 категориях с учётом типа сайта, режим сайта до 25 страниц, взвешенный скоринг 0–100 + буквенный грейд
- [x] Собственный robots.txt парсер (RFC-совместимая семантика групп и longest-match)
- [x] Детектор CSR/SPA: объём текста в серверном HTML + пустые точки монтирования (`#root`, `#app`…)
- [x] Проверка `llms.txt` (структура по llmstxt.org)
- [x] Анализ JSON-LD: типы сущностей, `author`, `datePublished`, `dateModified`, FAQPage/HowTo
- [x] Анализ «отвечаемости»: вопросные заголовки (4 языка), списки/таблицы, длина абзацев, объём
- [x] Метаданные, Open Graph, canonical, иерархия заголовков, alt-текст, семантический HTML
- [x] Технические сигналы: HTTPS, время ответа, редиректы, `X-Robots-Tag`, `noindex`, sitemap
- [x] Интерфейс и результаты проверок на 4 языках (en/ru/es/de), светлая/тёмная/системная тема, анимации
- [x] Postgres (Neon/Supabase): проверки, заявки, сообщения, оплаты, лицензии
- [x] Оплата: ключи Gumroad с автопроверкой; ссылки Boosty/Patreon с ручным подтверждением; Lemon Squeezy/Stripe
- [x] Юридический пакет под РК (оферта, конфиденциальность, cookie, возврат, согласие), сроки хранения, удаление данных
- [x] Страница успешной оплаты с ключом + письмо с ключом (Resend)
- [x] Ссылки «поделиться отчётом» с генерируемыми превью
- [x] Админ-панель: статистика, заявки (CSV), сообщения, лицензии, ручная выдача ключей
- [x] Страница контактов с формой, шаблоны Условий / Конфиденциальности / Возвратов
- [x] Публичный REST API `POST /api/v1/scan` с Bearer-авторизацией и CI-порогом
- [x] Rate limiting, SSRF-защита фетчера, таймауты, хэширование IP
- [x] 75 тестов: парсер, скоринг, локализация, лицензии, платежи, хранилище (в т.ч. на реальном Postgres)

**Осознанно вне MVP:** аккаунты/логин, мониторинг по расписанию, краул всего сайта,
PDF-экспорт, white-label, командные воркспейсы. Всё это — платные апгрейды следующей итерации.

## 6. Бизнес-модель

Продуктовая воронка: **бесплатный скан (хук) → пейволл на детальных фиксах → подписка**.

| План | Цена | Что даёт |
|---|---|---|
| **Free** | $0 | 5 сканов/день с IP, итоговый скор + категории, 3 верхние проблемы с фиксами |
| **Pro** | **$7/мес** | Безлимитные сканы, все фиксы, полные доказательства, экспорт JSON, API (500 сканов/день) |
| **Agency** | **$19/мес** | Всё из Pro + 2 000 API-сканов/день, полные отчёты для клиентов, приоритетная поддержка |
| **Lifetime** | **$49 одноразово** | Pro навсегда — стартовый оффер для первых клиентов |

Цены намеренно снижены на старте: задача первых месяцев — получить первых платящих
клиентов и отзывы, а не максимизировать чек. Поднимать цены стоит после ~30–50 клиентов.

**Юнит-экономика:** себестоимость скана ≈ 1 serverless-вызов + 3 HTTP-запроса → в пределах
free tier Vercel (100 GB-hours). При 1000 бесплатных сканов/день инфраструктура = **$0**.
Первый платящий клиент делает продукт прибыльным.

**Целевые метрики запуска:** 3% конверсии скан → email, 4% email → Pro.
100 сканов/день → ~3 лида/день → ~4 платящих/мес → **~$28 MRR на первом месяце**.
Это гипотеза для проверки, а не прогноз: реальные конверсии станут известны только после запуска.

## 7. Технологический стек

- **Next.js 15 (App Router) + React 19 + TypeScript strict** — SSR-лендинг и serverless API в одном деплое
- **Tailwind CSS** — быстрый, консистентный UI без дизайн-долга
- **Cheerio** — серверный парсинг HTML
- **Zod** — валидация входных данных на границе API
- **Postgres (Neon / Supabase, free tier)** — хранение данных
- **Gumroad / Boosty / Patreon** (Stripe и Lemon Squeezy — где доступны) — платежи без хранения карт на нашей стороне
- **HMAC-подписанные ключи + таблица лицензий** — быстрая проверка подделок и актуальный статус подписки
- **Resend** — письма с ключами и уведомления
- **motion, next-themes, lucide-react** — анимации, темы, иконки
- **Vercel Free Tier** — деплой в один клик

## 8. Риски и их снятие

| Риск | Снятие |
|---|---|
| Сайты блокируют наш фетчер | Честный User-Agent `CitableBot`, таймауты, graceful degradation — отчёт строится на том, что удалось получить |
| Клиент сканирует чужие сайты | Публичные GET-запросы к публичным страницам, как у любого SEO-краулера; rate limit; SSRF-защита от внутренних адресов |
| Копирование конкурентами | Моат — не код, а актуальная база AI-агентов и скоринговая модель; обновляется как контент-продукт |
| Смена правил AI-краулеров | База агентов вынесена в один модуль `lib/audit/crawlers.ts` — обновление занимает минуты |
